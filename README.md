# Photo of the Day — Unsplash

Выполнила Емельянова Ирина

Веб-приложение по **Уроку 3. Сетевые запросы** (JavaScript / Browser APIs).

Каждый раз при загрузке страницы (или по кнопке «Новое фото») приложение получает случайное изображение из Unsplash, показывает имя фотографа и позволяет ставить «лайки». Лайки и история просмотров сохраняются в `localStorage`.

---

## Возможности

- Случайное фото из Unsplash при каждой загрузке страницы
- Информация о фотографе (имя, аватар, ссылка на профиль)
- Кнопка «Лайк» + счётчик
- Сохранение лайков в `localStorage` (не сбрасываются при перезагрузке)
- История последних 12 просмотренных фото
- Возможность вернуться к любому фото из истории
- Адаптивный дизайн, тёмная тема
